INSTALLAZIONE SU GITHUB
1. Estrai lo ZIP.
2. Copia il contenuto nella cartella locale del repository dvs-gestionale.
3. Sostituisci tutti i file esistenti.
4. In GitHub Desktop: Commit to main.
5. Push origin.
6. Attendi 1-2 minuti e ricarica il sito con Cmd+Shift+R.
