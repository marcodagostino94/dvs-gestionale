DVS WORKSPACE V22.0 — POSTAZIONI REMOTE

Base: V21.0 Etichette chiare PULITA.

AGGIORNAMENTO DALLA V21
1. In Supabase > SQL Editor esegui tutto sql/migrate_v22_remote_rooms.sql.
2. Pubblica il contenuto di questa cartella nel repository dvs-gestionale.
3. Chiudi e riapri il Gestionale su ciascun dispositivo. In Settings >
   Informazioni deve comparire 22.0 prima di usare le nuove sale.
4. Apri Settings > Postazioni remote: Remoto 1–5 sono inizialmente disattivate.

USO
Attiva soltanto le remote necessarie. Compariranno dopo Sala 15 e nei menu
Assegnazione di Computer, Hardware, Avid e Plugin. Sono incluse anche nella
ricerca, nelle statistiche delle sale attive e nelle stampe.
Produzione, configurazione, note, postazioni ed etichetta funzionano come prima.
La disattivazione richiede conferma: libera tutte le risorse e i plugin,
azzera la Trial della postazione e nasconde la sala. Produzione, note,
configurazione e postazioni restano conservate per la riattivazione.
L'attivazione si sincronizza tramite lo stesso database del Gestionale.

Non occorrono interventi su notifiche, cron, Edge Function o Planning.
La migrazione può essere ripetuta senza disattivare le remote già attive.
I backup includono le nuove colonne delle sale. Dopo il ripristino di un
backup precedente alla V22, riesegui la migrazione per ricreare le remote.
Il normale backup JSON non incorpora i file allegati in Supabase Storage.

Il pacchetto conserva gli script SQL precedenti: per questo aggiornamento
esegui soltanto migrate_v22_remote_rooms.sql, non setup.sql o reset_test_data.sql.
