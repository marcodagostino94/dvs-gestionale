DVS GESTIONALE v4.0 — BASE PULITA

1. Apri Supabase > SQL Editor > New query.
2. Copia e incolla tutto il contenuto di sql/setup.sql.
3. Premi Run.
4. Pubblica questa cartella su GitHub Pages come facevi con le versioni precedenti.
5. Apri il link e accedi con email/password dell'utente già creato in Supabase.

Questa v4.0 non contiene i dati reali. Il database crea soltanto le 15 sale e una postazione vuota per sala.
I dati del File Master verranno importati nella v4.1.

SICUREZZA
- Nell'app è presente soltanto la Publishable Key, adatta all'uso nel browser.
- Non inserire mai una Secret Key / service_role nel repository.
- Tutte le tabelle hanno Row Level Security e sono accessibili solo agli utenti autenticati.

FUNZIONI PRESENTI
- Login Supabase e sessione persistente
- Dashboard separata
- Sidebar Mac/iPad e barra inferiore iPhone
- Sale con postazioni multiple
- CRUD Computer, Hardware, Avid e Plugin
- Assegnazioni dalla Sala o dalla scheda dell'elemento
- Sostituzione automatica: il vecchio elemento torna in Magazzino
- Sintesi non modificabile
- Archivio e registro modifiche predisposti

NON ANCORA PRESENTI
- Importazione File Master (v4.1)
- Face ID / Touch ID e ricerca globale (v4.2)
- Allegati e backup completi (versioni successive)
