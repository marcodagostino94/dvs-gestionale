DVS WORKSPACE V18 — INSTALLAZIONE NOTIFICHE AD APP CHIUSA

Il solo caricamento dei file V18 su GitHub Pages non completa l'aggiornamento.

1. SUPABASE — SQL EDITOR
   Eseguire una sola volta:
   sql/migrate_v18_push_reliability.sql

2. SUPABASE — EDGE FUNCTIONS
   Aprire la funzione send-expiry-notifications.
   Sostituire il codice con:
   supabase/functions/send-expiry-notifications/index.ts
   Poi scegliere Deploy updates.

3. SUPABASE — SQL EDITOR
   Aprire sql/configure_push_cron.sql.
   Sostituire YOUR_SERVICE_ROLE_KEY con la service_role key del progetto.
   Eseguire lo script per aggiornare il cron delle 09:00 Europe/Rome.

4. PUBBLICAZIONE
   Pubblicare tutti i file della cartella DVS_Gestionale_V18.

5. OGNI DISPOSITIVO
   Aprire almeno una volta la V18 con connessione Internet.
   Entrare in Settings → Notifiche.
   Verificare che compaia "Notifiche attive".
   Premere "Prova dal server" e attendere l'avviso.

6. VERIFICA AD APP CHIUSA
   Chiudere completamente l'app dopo il test server.
   Le notifiche pianificate vengono inviate dal server e non richiedono l'app aperta.

DIAGNOSTICA
Se il test server non arriva, eseguire:
sql/diagnose_push_v18.sql

La query mostra cron, ultime esecuzioni, dispositivi registrati e consegne effettuate.
