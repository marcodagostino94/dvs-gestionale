DVS WORKSPACE V18 — CHANGELOG TECNICO

MENU IPHONE
- Nuova navigazione Liquid Glass attiva esclusivamente fino a 600 px.
- Le sei icone restano fisse e sempre visibili.
- La sola capsula rossa segue il dito mediante una posizione frazionaria CSS.
- Al termine dello swipe la capsula si aggancia all’icona più vicina e apre automaticamente la pagina corrispondente.
- La posizione della capsula è calcolata tramite offsetLeft/offsetWidth reali: nessun errore cumulativo e nessun taglio alle estremità.
- Icone e sezioni originali del Gestionale mantenute.
- Breakpoint iPad e layout desktop non modificati.

BACKUP
- Eliminato l’aggiornamento anticipato di localStorage all’avvio del download.
- Mac: scrittura tramite File System Access API; il successo viene registrato solo dopo writable.close().
- iPhone/iPad: esportazione tramite Web Share API; l’annullamento (AbortError) non aggiorna lo stato.
- Nome file e timestamp sono salvati nella nuova tabella Supabase app_settings solo dopo l’esportazione confermata.
- app_settings è sincronizzata via Supabase Realtime, rendendo lo stato comune a Mac, iPad e iPhone.
- I file JSON di backup esistenti e il relativo formato non vengono alterati.

INSTALLAZIONE
- Su un database esistente eseguire una sola volta sql/migrate_v12_backup_status.sql.

NOTE HARDWARE
- `smartNote(notes)` aggiunto alle schede dell’inventario Hardware.
- `smartNote(notes)` aggiunto alle risorse Hardware assegnate nelle Sale.
- `smartNote(notes)` aggiunto alle schede Hardware non assegnate nelle Sale.
- Nessuna migrazione SQL richiesta per la V14.

SELETTORE AVID NELLE SALE
- La label delle scelte Avid include ora `code`, `avid_type` e `system_id`.
- Il fallback visuale per un System ID non compilato è `—`.
- Nessuna modifica alla logica di assegnazione o allo schema dati.

NOTE NEI SELETTORI DELLE SALE
- `smartNote(x.notes)` applicato a ogni risorsa generata da `assignmentSheet`.
- La copertura comprende Computer, Hardware, Avid e Plugin.
- Il componente mantiene escaping HTML e rendering condizionale già utilizzati nel resto dell’app.

STABILIZZAZIONE TESTATA
- Neutralizzata la scala di `body.header-compact .topbar h1`.
- Disabilitata la transizione del titolo sticky per evitare ridisegni sub-pixel.
- Aggiunti isolamento compositivo e backface nascosta alla topbar.
- Nessuna modifica alla logica di scroll o ai dati.

AFFIDABILITÀ NOTIFICHE
- Payload server nel formato Declarative Web Push (`web_push: 8030`).
- Fallback imperativo mantenuto nel Service Worker per browser precedenti.
- Aggiunto `app_url` alle sottoscrizioni e rinnovo automatico all’avvio.
- Test notifiche spostato dal dispositivo alla Edge Function.
- Cron eseguito alle 07:00/08:00 UTC con guardia sulle 09:00 Europe/Rome.
